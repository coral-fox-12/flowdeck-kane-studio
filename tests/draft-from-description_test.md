# Draft from description generates a login flow

## Generate drafts from a login description

In the "Draft from description" section, type "user logs in with valid credentials and sees the dashboard" into the Feature description box and click "Generate drafts". Then verify at least one drafted objective is shown that mentions login and contains a verify clause.

## Save the first draft as a flow

Click "Save as flow" on the first draft. Then verify the Flows list now contains a flow without a SAMPLE badge.
